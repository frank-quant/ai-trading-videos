# 01 · 让 ZCode 从零装 TradingAgents-CN

**视频 03:57** · 在一个**空目录**里打开 ZCode,然后:

```
https://github.com/hsliuping/TradingAgents-CN

读一下 README，用 docker 帮我部署到本地。
遇到问题你自己查自己改，需要我提供什么再问我。
```

就这三行。仓库地址 + 一句要求 + 一句授权。

## 为什么最后一句不能省

「遇到问题你自己查自己改」是**给它授权**。

没这句,它每执行一步都会停下来问"要不要执行 docker compose up",
过程会碎成一堆确认弹窗。加了之后它会一路自己跑,遇到报错自己翻文件、自己修。

「需要我提供什么再问我」留了个口子——它会主动问你要 Tushare Token、API Key,
而不是瞎猜或者卡住。

## 会遇到的

**这个项目需要 MongoDB 和 Redis**,必须走 Docker,pip 装完跑不起来。ZCode 读完 README 会主动提醒。

**第一次登录会失败。** 官方给了默认账号密码,但数据库里那条用户记录不存在——
这是 Docker 部署流程的缺口。把报错原样贴给它:

```
〔粘贴登录失败的报错〕
```

它会去查、定位到数据库缺默认用户,然后调初始化脚本创建管理员,还会用 API 验一遍确实修好了。
视频 04:33 那段就是这个过程。

# 交付物复核说明

本目录保留模型原始交付，整理过程没有改动其财务数据、公式、报告或回测代码。下列内容概括视频中评价的范围，便于阅读原件时定位。

| 任务 | 阅读与复核要点 |
|---|---|
| 宇树投委会 | 约25页PPT及不同机构完整研报。第10页正文区分行业应用与明确工业场景，但标题口径混用；估值情景中的利润、PE、折现率及概率属于模型假设 |
| 海力士财报 | 季度经营与非经营损益、现金流解释及关键数据表。利润与现金流口径应分别阅读；简化自由现金流未扣除所有投资与其他资本义务 |
| Meta财务预测与估值 | 以季度模型为主要分析对象。估值日、完整第四季度现金流与现金债务余额日期尚需衔接；敏感性表的各增长率列共用基准增长率下的终值现金流 |
| ETF轮动回测 | 原持仓的分红归属正确；可用现金在除息日确认，未按实际支付日模拟到账。应结合代码、交易明细和报告阅读，原件没有因整理而修正 |
| 数据库筛选 | 15家中13家符合财务条件，再按营收取前10。核对范围为数据库返回及筛选计算；历史截止日可见版本、披露时点和后续重述仍有限制 |
| IPO监管问询 | 报告为依据公开材料拟议的问询研究；提出疑问不等于已发现错报、违规或实际监管结论 |

年度模型能够作为长期DCF的合理交付；需要季度细化时，通过补充要求继续交付，是任务理解与交付能力的一部分。Meta不按年度、季度分别计算资源消耗。

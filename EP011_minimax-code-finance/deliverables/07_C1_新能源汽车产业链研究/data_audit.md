# data_audit.md — 新能源汽车投资关系数据审计说明

> 配套文件：`relations.csv`（300 条投资关系）、`sources.csv`（714 条来源台账，其中本阶段新增 `REL-*` 51 条）
> 数据主体：赛力斯集团股份有限公司、比亚迪股份有限公司、宁德时代新能源科技股份有限公司、小米科技有限责任公司 / 小米汽车科技有限公司及其主要被投主体
> 本阶段取数日：2026-11-01｜项目统一信息截止日：2026-10-23

## 0. 一句话结论

本表已用**两个独立口径**（企查查工商登记快照 + 可回查的上市公司公告转述）核实四家核心主体及其一级被投公司的直接股东、对外投资与实际控制关系，共建立 300 条带来源、带信息日期、带口径标注的关系；**所有非股权关系单列，所有穿透聚合值逐字引用未自算，所有人物/机构连线均以一方可回查的原始记录为前提**。同时明确登记了 **12 类被排除的关系**与 **10 类当前数据不能支持的结论**，避免下游把这份表误读成"股权图谱 = 合作关系图谱"。

## 1. 关系类型词表（本表的受控词汇）

`relations.csv` 第 6 字段 `关系类型` 只允许下列取值，每类含义互不重叠：

| 关系类型 | 条数 | 判定标准 | 是否可画成股权 |
|---|---|---|---|
| 对外投资持股 | 140 | 工商登记"对外投资"记录的持股比例（被投方为起点方持有股权的标的） | 是 |
| 直接股东持股 | 91 | 工商股东名册第一层直接股东 | 是 |
| 直接股东持股（工商登记口径） | 10 | 同上，但专用于与"上市公司股东持股"并列披露的湖南裕能 10 名股东 | 是 |
| 上市公司股东持股 | 10 | 上市公司定期报告披露的前 10 名股东（报告期末时点） | 是 |
| 同一投资方覆盖 | 20 | 同一主体出现在 ≥2 家公司的股东/投资名册中（聚合标签，指向具体持股事实） | 指向的是具体股权事实，非新事实 |
| 合资公司持股 | 15 | 合资/合营公司股东名册中的持股 | 是（但为合资口径，非控股口径） |
| 实际控制 | 6 | 企查查穿透引擎返回的终值（总持股比例 / 表决权比例） | 否——**实控 ≠ 大比例持股** |
| 参股上市公司 | 3 | 持有 A 股/港股上市公司股份的产业参股 | 是 |
| 并购取得控股权 | 1 | 通过并购/重组取得标的控制权（含交易对价口径） | 是 |
| 减持（持股变动） | 1 | 已披露的持股比例变动事件 | 是 |
| 战略合作（非股权） | 2 | 已披露的战略/框架合作协议，无持股条款 | **否** |
| 供应链配套（非股权） | 1 | 供货/配套关系，无股权关系 | **否** |

**硬约束落地方式**：非股权行的第 7 字段（持股比例或披露状态）一律写"未披露持股比例"或"不适用"，**不出现任何百分数**。`scripts/validate_relations.py` 对此做了机器校验（"非股权关系行均未携带股权比例"），并反向校验"股权类关系行均带比例"。

**本阶段没有 L1 级证据。** 全部关系行的来源均为 L2 或 L3，见 `sources.csv` 第 14 字段。

## 4. 被排除的关系（12 类，逐条给出排除理由）

| # | 被排除的关系 | 排除理由 | 处理方式 |
|---|---|---|---|
| E1 | 吕向阳 → 比亚迪以外的任何主体 | 企查查股东检索"吕向阳"返回"已全量扫描该主体股东信息数据库，未发现任何记录"；无任何可回查证据 | 只保留"吕向阳 → 比亚迪 7.87%"这一条有据关系，**不外扩** |
| E2 | 阿维塔科技(重庆)有限公司 → 阿维塔科技（重庆）股份有限公司 的更名/同一性 | 两个登记名称不同（前者为公告中的受让主体，后者为工商股东名册主体）；**是否同一主体更名未获一手证据** | 两主体分别登记，引望 10% 的受让方名称照录公告原文并加注 |
| E3 | 任正非 → 华为技术有限公司 → 引望 的持股路径 | 穿透引擎只返回实控人终值，不返回逐路径中间层 | 只登记"任正非 → 引望（实际控制，总持股0.3865%、表决权80%）"，**不臆测中间主体** |

## 6. 当前数据不能支持的结论（10 条，这是本表最重要的使用限制）

1. **不能计算任何"实际持股 / 穿透持股"合计。** 本表全部为第一层直接比例。企查查连接器的口径说明明确禁止把各层比例相乘自行重构穿透路径。任何"前十大股东合计比例""实际控制人合计持股比例""某集团合计持股 X%"的说法在本表上都不成立。
2. **不能据本表判断业务合作强度或订单流向。** 股权关系 ≠ 供货关系 ≠ 品牌合作 ≠ 换电生态合作。第二阶段 `industry_report.md` 的产业链配套结论不能由本表推出，反之亦然。
3. **不能说"宁德时代与比亚迪在湖南裕能地位相当"。** 2026-06-30 口径为 6.13% vs 2.65%，相差逾一倍；且宁德时代在 Q2 已减持至 4.99999%。两个口径不可混用、不可叠加。
4. **不能说"赛力斯与华为是股权关系"。** 赛力斯上市公司不直接持有引望；股权在赛力斯汽车（93.633% 控股的子公司）这一层；且引望 80% 仍在华为技术手中。
5. **不能说"长安汽车控制引望 10% 股权"。** 引望受让方的登记名称与工商股东名册中的阿维塔股份公司不一致（见 E2），且长安在阿维塔的直接持股为 40.99%（非全资）。本表不支持穿透到长安对引望的权益。
6. **不能断言"小米在动力电池环节具有控制权"。** 小米在时代北汽 5%、在比亚迪半导体系于 1.72%（且非控股）、在欣旺达动力 5.34%，全部为参股。
7. **不能推断四家核心主体之间存在相互持股或循环持股。** 本表未发现任何一条此类关系；任何"赛力斯与比亚迪互相持股""宁德时代与比亚迪交叉持股循环"的说法在现有数据下无证据。
8. **不能把工商快照比例当作"截至 2026-10-23"的比例。** 284 条关系的信息日期为工商快照日 2026-11-01，与项目截止日不同源；每条已标【晚于截止日】，但**使用时必须按快照日而非截止日理解**。
9. **不能把"同一投资方覆盖"读作"协同动机"或"一致行动"。** 共现是事实，动机与一致行动是判断，本表不做判断。
10. **不能基于本表对股权关系做时点化估值贡献判断。** 信息日期横跨 2024-01 至 2026-11，且工商口径与定期报告口径混存；且**恒生行情连接器仍不可用**，股权关系的市值影响无法量化（承自第一阶段 `scope.md` §9 留空项 #1）。

## 9. 投资关系图谱（investment_graph.html）的口径与合成关系登记

`investment_graph.html` 完全由 `relations.csv` + `sources.csv` 构建，**不引入任何新的数据来源或新的事实断言**。但图谱在渲染前对底稿做了两件必须登记的处理：结构化合并，以及一次**受控规则的合成**。否则图上的边数（284）与底稿行数（300）无法直接对账。

### 9.1 合并（可逆、不新增信息）

| 处理 | 规则 | 结果 |
|---|---|---|
| 边合并 | 按（起点 → 终点）有序对合并 | 300 行记录 → 246 组有序对 |
| 主体归集 | 去重后按主体类型归入公司 / 投资机构 / 人物 | 234 个主体（公司 141 / 投资机构 78 / 人物 15） |
| 多口径并存 | 同一对主体有多个口径时**不择一**，边详情面板逐条展开，分别列出比例、口径、信息日期、source_id | 与 §5 口径冲突并列披露一致 |

图上边总数 = 246（底稿合并）+ 38（合成）= **284 条**。

### 9.2 合成关系：共同投资关系（38 对）—— 唯一的新增信息

底稿 §3.8 已审定的"同一投资方覆盖"是**聚合标签**（一个投资方对其被投公司的标注），本身不构成"两家公司之间存在关系"。为了让图能表达"两家公司被同一个投资方覆盖"，构建期按下列**受控规则**合成边：

1. 共同投资方必须是**第三方投资机构**（类别为投资机构的公司主体不参与），排除以公司主体充当共同投资方；
2. 排除被动持股通道：`中央结算|Nominees|NOMINEES|证券投资基金|交易型开放式指数|社保基金|保险股份|回购专用|专户`；
3. 排除母子公司族内配对：若该共同投资方对任一方持股 ≥ 90%，视为控制关系而非共同投资，跳过；
4. 双方持股均 ≥ 0.2%；
5. 叠加 §3.8 中已审定的"同一投资方覆盖"记录；
6. 跳过已有直接股权关系的有序对（2 对）。

结果：**38 对**，每对在图上标注共同投资方名称、双方持股比例、信息日期与 source_id，并在详情面板附"并非二者相互持股"的明确警示。

> **口径声明**：合成边表示"存在共同投资方"这一**可回查事实**，**不表示两家公司相互持股**，也**不表示共同投资方对两家公司构成控制**。合成边已计入图谱的"已核实关系"（其底层持股记录均已核实），但在与 `relations.csv` 对账时应单独列示。

| 图上位置 | 口径 |
|---|---|
| 顶部统计条 | **全图口径**，不随筛选变化：公司 141 / 投资方 78 / 人物 15 / 已核实关系 281 / 未核实关系 3 |

### 9.4 图谱不能支持的结论

1. 图谱的边**不代表时间序列**：同一条边可能同时包含不同信息日期的多条记录；做时点判断仍须回到 `relations.csv` 的"信息日期"字段。
2. **跳数不等于持股链条长度**：1 跳 / 2 跳只表示图上的邻接层数，跨越的中间主体比例可能极小，不构成控制或重大影响的证据。
3. **布局位置不承载信息**：径向分环与角向排序仅为可读性安排，不代表持股比例、控制力或关联强度。
4. 图谱**不含市值维度**（恒生行情连接器承自第一阶段不可用），不能用于计算股权关系的市值影响。
5. 合成边**不可反推**为任一方的持股关系，也不可用于认定共同投资方对任一方的控制。

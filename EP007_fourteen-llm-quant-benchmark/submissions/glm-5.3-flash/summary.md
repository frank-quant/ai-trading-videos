### 🔑 两档做了同一个诊断，却做了相反的决定

**两档都识破了目标函数的同一个缺陷：**

> **Flash（design.md）**：The gap penalty is one-sided. `loss = -(vs - 0.5·max(0, ts-vs))` 惩罚 train>valid，却*奖励* valid>train。
> **旗舰（design.md）**：gap penalty 是不对称的，忽略 valid ≫ train，所以 loss 会悄悄奖励训练集 edge 很小的参数组——argmax 利用的正是这一点。

**但结论相反：**

- **旗舰**：推翻 loss，手动挑 e303（"e243 全部分数来自验证那一年，这是训练好验证差的镜像失败模式"）
- **Flash**：服从 loss 取 argmax，但把风险明确披露 —— *"valid >> train (2.83 vs 0.52). The fixed loss cannot punish this direction... **My honest expectation for the unseen test period is well below the validation Sharpe.**"*

考题两句话各支持一边：「You MUST use the PROVIDED loss」支持 Flash，「reasoned disagreement is credited」支持旗舰。

**⭐ 结果：旗舰对。** 而且 Flash 预言中了自己的失败，连它标出的 `n_short=1` 集中度风险也兑现了——熊市跌 46%，它的空头只赚 **0.06%**（旗舰是 +6.08%）。

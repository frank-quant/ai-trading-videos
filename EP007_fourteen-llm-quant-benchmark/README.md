# EP007 · 14 个大模型同一道量化题（第二季）

📺 看视频：[B站](https://www.bilibili.com/video/BV1ijYB6QE1Y/) · [YouTube](https://youtu.be/5wEQiwCwGY0)

把 **14 个模型**关进同一场考试：同一份题目、同一份数据、同一笔手续费、同一个目标函数，
各自用**自己的官方 harness** 写一套能做多也能做空的量化策略。
然后扔进一个它们从没见过的年份——那一年大盘跌 **44.95%**。

**只有 1 个模型的样本外收益为正（Qwen3.8-Max，+1.74%）。**
**把回测末根 K 线的机械强平剔掉之后——0 个。**

这一季比上一季多了两件事：模型从 4 个加到 14 个，并且加了**同厂商档位对照**（GPT-5.6 三档、GLM 两档）。

本目录放的是**可复现的全部材料**：题目原文、脚手架、14 个模型的完整交付物、审计脚本和结果。

## 这场考试的几个结论

**1. 同一张卷子是可验证的。** 14 个模型的 `GOAL.md`、`README_FOR_MODEL.md`、
`cross_sectional_base.py`、`EP004ValidLoss.py` **MD5 全部一致**，自己 `md5sum` 一遍就能核。

**2. 搜索预算没人用满。** 上限 2000 轮，实际用量 60 ~ 597 轮，没有一个模型跑到三分之一。
从收敛曲线看，它们停下来的时候曲线早就平了。

**3. 脚手架有路径依赖。** 题面写明「策略家族完全由你决定」「脚手架用不用随你」，
结果 12 个顺着我提供的横截面基类走了，只有 2 个自己从 `IStrategy` 从头写
（Grok 写了横截面，Gemini 写的是逐币趋势跟踪）。

**4. 冠军的钱不是策略赚的。** Qwen 揭盲期 469 笔成交里，452 笔按它自己的信号平仓，净亏 94.3；
剩下 17 笔是回测末根 K 线的机械强平，赚了 268.1。**剔掉强平，14 个模型全为负。**

## ⚠️ 两套夏普，别混用

这一期有两个夏普定义，差 0.4 ~ 0.6：

- **控制台口径** `console_metrics.json` —— Freqtrade 的 `Sharpe (daily wallet balance)`，每天按钱包余额盯市。**主榜排名用它。**
- **目标函数口径** `seg_*.json` —— `EP004ValidLoss._sharpe_daily`，按平仓那天归集已实现盈亏。**模型自报的数字是这套**，能剔掉末端强平的也只有这套。

**拿控制台那套去比模型自报的数字，会把 14 个模型全部判成虚报。** 这个坑我自己踩过，
口径规则写在 [`results/报告口径规范.md`](results/报告口径规范.md)。

## 诚实披露

- **样本外那一年是熊市（大盘 −44.95%），而训练和验证段是牛市。** 这是最诚实的压力测试，
  但**不是中性样本**，换个年份结论可能不一样。
- **幸存者偏差**：这 20 个币是站在今天回头挑的。
- **滑点乐观**：扁平万分之六，没有市场冲击模型。
- **成本口径**：走 API 的按平台账单原值记；订阅制的（Codex / Claude Code）按会话日志 token 量
  × 官网目录价折算，是等效成本不是实付。智谱两条由体验包抵扣，实付 ¥0，金额本身准确。
  DeepSeek 是唯一按时段定价的，记的是实付。每家的口径都写在各自的 `verified/cost.json` 里。
- **六个分数里，稳健、表现、性价比有客观依据；无作弊、代码、诚实是我读完代码和文档后的主观打分。**
- **每个模型只考了一次**，没有重复跑取分布。这是这份榜单最大的局限。

**这是一次考试的成绩，不是模型能力排名。** 相邻名次之间的差距小于重复跑的方差，
不要用它来论证「A 比 B 强」。

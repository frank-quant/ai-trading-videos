## 1. 摘要：这一轮产业链发生了什么

### 1.1 【事实】

1. **利润在产业链内部显著上移。** 2026 年一季度锂电池环节利润占比从 2024 年的 96.43% 降至 **52.21%**，同期能源金属与电池化学品利润占比分别升至 **23.42%** 和 **22.33%**〔M-0148 / BAT-113、M-0149 / BAT-115、M-0150 / BAT-117〕。2026 年上半年上游资源、中游材料、电池、整车公司归母净利润总额从上年同期的 76.8 亿元升至 **339.3 亿元**〔M-0151 / BAT-119〕。

2. **锂价上行把资源端从周期底部拉回，但分化极大。** A 股 13 家规模以上锂矿及锂盐企业 2026 年上半年合计营收约 **870 亿元**（上年同期约 400 亿元，+1.2 倍），净利润合计 **264 亿元**（上年同期约 52 亿元，增长超 4 倍），12 家盈利、仅江特电机亏损〔M-0001 / LI-010、M-0002 / LI-012、M-0003 / LI-014〕。盐湖股份锂盐产品毛利率 **83.46%**，江特电机整体毛利率仅 **6.92%**，差距超过 10 倍〔M-0012 / LI-036、M-0041 / LI-101〕。

3. **储能接棒动力成为电池端第一增长引擎。** 2026 年上半年储能电池累计销量 **318.1GWh**（+83.4%），1–7 月 **374.2GWh**（+78.6%）〔M-0142 / BAT-101、M-0143 / BAT-103〕；亿纬锂能储能电池出货 **44.46GWh** 已超过其动力电池出货 **35.76GWh**〔M-0114 / BAT-045、M-0115 / BAT-047〕。

4. **规模扩张与毛利率下行在电池端同时发生。** 宁德时代上半年营收 +54.80%、归母净利 +41.98%，但综合毛利率同比 **-1.11pct** 至 23.93%、动力电池毛利率同比 **-1.78pct** 至 20.63%〔M-0104 / BAT-025、M-0105 / BAT-027、M-0106 / BAT-029、M-0107 / BAT-031〕。8 家电池厂中仅瑞浦兰钧毛利率同比提升〔M-0130 / BAT-077〕。

5. **整车端总量承压、结构剧烈分化。** 2026 年 9 月国内乘用车零售 161.8 万辆，同比 **-28.0%**；1–9 月累计零售 1333.4 万辆，同比 **-21.7%**〔M-0275 / OEM-078、M-0276 / OEM-080〕。同期比亚迪品牌 1–9 月销量 134.41 万辆、份额 16.52%〔M-0244 / OEM-001〕，零跑 50.70 万辆（+45.9%）升至第三并反超特斯拉〔M-0246 / OEM-007〕。

6. **零部件与智驾环节普遍"量增利减"。** 拓普集团营收 +9.78% 但归母净利 **-21.03%**〔M-0173 / ADP-001、M-0175 / ADP-007〕；德赛西威智能驾驶业务收入 **-5.53%**、该业务毛利率由约 19.74% 降至 **14.49%**〔M-0196 / ADP-050、M-0197 / ADP-052〕。

7. **智驾利润池从硬件向软件/IP 迁移。** 地平线上半年授权及服务收入 11.29 亿元（+52.7%），首次超过总收入一半，毛利率 **90.4%**〔M-0203 / ADP-064、M-0204 / ADP-066〕；其经调整净亏损反而由 13.33 亿元扩大至 16.71 亿元〔M-0206 / ADP-070〕。

8. **电池回收市场规模与合规产能严重错配。** 2026 年国内锂电回收市场规模测算 **527 亿元**（2025 年 222 亿元，+137.4%），但白名单 156 家企业名义产能 423.3 万吨、2025 年行业产能利用率仅 **16.4%**，超六成退役电池流入灰色渠道〔M-0291 / AFT-021、M-0293 / AFT-025、M-0294 / AFT-027、M-0295 / AFT-029、M-0304 / AFT-047〕。

### 1.2 【判断】

1. **本轮的核心变化不是需求爆发，而是产业链利润分配的重排。** 整车销量增速已明显放缓（1–9 月 NEV 销量 +11.1%，第一阶段数据），但上游资源与中游材料的利润弹性远大于销量弹性，原因是供给侧同时发生扰动（检修、换证、复产节奏）与需求侧同时发生结构切换（储能）。这意味着**周期位置已从"量的故事"切换到"价与结构的故事"**，研究重心应放在成本曲线与供需平衡表，而非单纯的销量同比。

2. **储能是当前唯一可以同时支撑"量"和"价"的终端需求。** 动力端增速受国内乘用车零售负增长拖累，储能端则由全球电力系统建设驱动且仍在加速。这一判断的直接含义是：**电池厂、锂盐厂、隔膜电解液铜箔等材料环节的景气排序，储能量产占比高的企业优于纯动力配比企业**。

3. **中间环节（域控、激光雷达、传统零部件）正在丧失定价权。** 量在增长，但毛利率被年降和整车厂议价权压缩。这不是短期现象，而是硬件标准化后的结构性结果。**利润会向两端迁移：一端是拥有自有资源的资源商，另一端是能跨车型复用的软件/IP 供应商。**

4. **固态电池的产业位置需要下调预期。** 已发生的商业化集中在半固态且规模有限（行业或有 10GWh 级出货〔M-0155 / SLD-001〕），全固态普遍处于试制与验证阶段。**当前兑现顺序是设备 → 已供货的正极材料 → 电解质（等重复采购信号）**，把固态当成整车厂的量产催化来做，时点容易错。

5. **电池回收是一个"政策确定性高、但产业盈利兑现慢"的环节。** 数字身份证与车电一体报废制度已落地（2026-04-01 生效〔M-0309 / AFT-057〕），供给侧出清也在推进（2026-07-30 100 家梯次企业移出名单〔M-0310 / AFT-059〕），但渠道成本倒挂（合规企业要承担环保、安全、税收、溯源成本，无法与非正规渠道竞价）这一核心堵点尚未被机制性解决。**看到"六大基地合规产能利用率较 Q2 提升 8–12pct"〔M-0312 / AFT-063〕这类边际改善时，需要区分是政策回流还是渠道建设见效。**

### 2.4 【判断】

1. **成本曲线是解释锂企分化的唯一主变量。** 盐湖卤水提锂成本 3–5 万元/吨、锂辉石 5–7 万元/吨、锂云母 6–8 万元/吨〔M-0059 ~ M-0061 / LI-142、LI-144、LI-146〕。在 16 万元/吨的均价下，成本最低的一档每吨利润超过 10 万元，而外购矿石的加工企业原料成本同步上行。江特电机的处境是这条曲线的极端样本：核心锂矿茜坑尚未开采，锂矿石原料主要依赖外购，因此**即便在锂价大涨的半年仍然亏损**〔M-0039、M-0040〕。研究中筛选锂标的，"是否拥有低成本自有矿源"应当优先于"是否有产能扩张计划"。

2. **本轮涨价的供给侧成分高于需求侧成分。** 需求端排产数据是支撑的：8 月国内电池样本企业排产 203.76GWh、环比 +8.73%〔M-0068 / LI-160〕，9 月正极材料排产市场普遍预计环比再增 8%~10%〔M-0069 / LI-162〕。但同期供给侧同时发生检修、换证、到港不及预期三件事。**这意味着一旦上述扰动解除，价格回吐的速度可能快于需求增速的变化。**

3. **全球化风险正在从"价格风险"转为"政策与主权风险"。** 锂三角与津巴布韦通过限制出口、设定熔断底价、暂停出口等方式最大化资源价值并推动本国产业升级；天齐锂业在半年报中明确提示出口管制、生产配额、强制加工与政府干预带来的风险。**对拥有海外矿权的公司，矿权所在国的政策变动已是与锂价并列的一级风险变量。**

### 3.2 【判断】

1. **电解液与隔膜是本轮材料端弹性最大的两个环节，但弹性来源不同。** 电解液的弹性来自六氟磷酸锂供需格局优化与产能利用率接近满产（天赐综合毛利率 33.55%，是新宙邦电池化学品业务的**两倍以上**）；隔膜的弹性来自价格周期回升（恩捷毛利率 +17.99pct），属于典型的价格驱动型修复。**前者更接近结构性改善，后者更接近周期反弹，估值含义不同。**

2. **湖南裕能的报表里有一个需要单独标注的现金流信号。** 收入 +142.92%、净利 +853.51%，但经营活动现金流净额为 **-17.63 亿元**〔M-0087 / MAT-049〕。公司给出的解释（票据支付长期资产购置款，剔除后为 +3.81 亿元）是合理且可验证的，但**在解读任何"量增利增"材料企业时，都应同时看经营现金流与存货变动**，否则容易高估利润的现金含量。

3. **负极是材料端里成本传导最不充分的环节。** 负极产品毛利率虽有提升（翔丰华 +6.25pct），但原材料涨价形成的是成本端压力，盈利分化明显；杉杉股份人造石墨出货市占 21% 居首、负极销量 +54.92%（第一阶段数据），但行业整体利润仍受挤压。**在锂价上行周期里，负极环节的议价能力最弱。**

4. **设备端是本轮"扩产 + 固态新工序"叠加受益的环节，但必须区分总量与结构。** 先导智能上半年新增订单约 180 亿元、同比约 +50%~60%〔M-0102 / MAT-080〕，这是**总新增订单**，储能与动力约各占一半，**不能全部归因于固态**。同时 Q2 毛利率环比下降约 3pct，说明订单增长尚未完全转化为利润。固态相关的确定性落点是设备交付：利元亨已向国内头部客户陆续交付全固态整线设备，海目星披露固态设备订单并与头部电池厂合作推进产线建设〔M-0171 / SLD-037〕。

1. **"一超多强"正在变为"一超多强、分化加剧"。** 8 家电池厂中 6 家毛利率同比下行，只有瑞浦兰钧提升。规模领先者（宁德时代）靠份额回升对冲了部分价格压力，而二三线企业要么靠规模效应扭亏（瑞浦兰钧、中创新航），要么在成本压力下盈利困难（正力新能、孚能科技）。

3. **储能接棒是需求侧的结构性变化，不是季节性波动。** 亿纬锂能储能出货 44.46GWh 超过动力 35.76GWh，且行业上半年储能电池累计销量 318.1GWh（+83.4%）显著快于动力；东吴证券预计 2026 年全球储能电池出货 1100GWh（+70% 以上）〔M-0144 / BAT-105〕。**在研究电池企业时，把储能收入/出货单列出来看，比看整体毛利率更能反映真实景气度。**

4. **"去宁东化"要按供应链管理常识理解，不能过度解读。** 开放二供是整车厂的标准做法，头部企业在新车型首发供应中仍多居首位，**行业格局短期内难有根本改变**。但它的真实含义是：**整车厂对电池环节的议价能力在持续增强，这是电池厂毛利率下行的根本原因，比单纯的"价格战"更本质。**

### 5.2 【机构观点】

国泰海通林隆鹏、银河罗峰：2026 年半固态小规模装车，2027 年头部企业全固态小批量试制装车，**距大规模量产尚远**；设备环节（干法电极、等静压）率先受益，2026–2027 年中试线建设先落地〔M-0172 / SLD-039〕。

### 5.3 【判断】

1. **固态不是一个单一事件，而是"半固态—准固态—全固态"三段不同的产业化阶段，必须分开记账。** 半固态已有商业出货且 2026 年 7 月国标实施收紧了包装口径（120℃ 真空失重率 ≤0.5%），这实际上是在**淘汰把半固态包装成全固态宣传的做法**，对行业是好事，但也意味着过去某些"固态出货量"的水分需要重新审视。

2. **兑现顺序是清晰的：设备 → 已供货的正极材料 → 电解质。** 电池厂把样品变成能稳定生产的产品，顺序必然是先买设备、再反复测试材料、最后才大批量卖电池。**把固态当成整车厂的量产催化剂来做，时点容易错**；而从设备订单与产线贯通去跟踪，是更早、也更可验证的信号。

3. **不要把"产线贯通""样车下线""中试线贯通"当成产能。** 设计产能衡量的是工厂规模，**连续生产的合格电芯与实际交付才决定材料采购量**。上述 8 条进展中，真正进入商业化交付阶段的仍只有半固态。

### 6.3 【判断】

1. **零部件的利润率问题不是短期周期问题。** 行业层面，2026 年前 8 个月汽车行业销售利润率降至 **3.6%**，利润总额同比 -16%〔M-0193 / ADP-044〕；华光股份新能源配套毛利率从 2023 年 13.95% 降到 2025 年 8.21%〔M-0194 / ADP-046〕。**上游整车厂的降本压力会通过年降机制持续向下传导，零部件厂的单车价值量与毛利率需要分别看**。

2. **跨界业务目前对零部件企业报表的贡献可以忽略。** 拓普集团机器人执行器收入 1404.77 万元，占营收约 0.1%〔M-0183 / ADP-024〕；光洋股份机器人业务收入 999.41 万元、毛利率 **-22.56%**〔M-0195 / ADP-048〕。**在研究"零部件 + 机器人"叙事时，必须先确认该业务是否已产生正的、可重复的利润贡献。** 液冷是另一个方向：中金测算 2026 年全球智算中心液冷市场 1147 亿元（+273%），拓普液冷/热管理累计订单已至 17.5 亿元〔M-0184 / ADP-026〕，量级上更值得跟踪。

3. **智驾链的价值正在从硬件向"能复用的软件/IP"转移，这可以被财务数据直接验证。** 地平线授权及服务收入 11.29 亿元已超过产品收入 9.26 亿元，毛利率 90.4%；千里科技智驾毛利率 71.21%；Momenta 出现 6.07 亿元软件许可收入。相反，德赛西威的智驾硬件毛利率从 19.74% 降到 14.49%〔M-0197 / ADP-052〕。**判断一家智驾供应商的可持续性，应当看授权/许可/软件收入占比，而不是看定点数量。**

4. **"定点越多可能成本越高"是当前智驾行业被低估的负面机制。** 过去一家车企一个方案、一款车型一套工程团队的开发方式，无法支撑软件规模效应；项目无法高度复用时，收入增加的同时人力与研发成本同步增加。Momenta 接近经调整盈亏平衡，实质是研发杠杆开始出现；地平线经调整净亏损反而扩大，说明仍在选择"扩大投入 + 芯片 + HSD + IP 授权同时进攻"的路径。

5. **RoboTaxi 仍处投入期，与 L2+ 已形成反差。** 2026H1 小马智行收入 7047 万美元、研发费用 1.04 亿美元；文远知行收入 3.46 亿元、研发费用 7.98 亿元〔M-0220 / ADP-099、M-0221 / ADP-101〕。**L2+ 已经过"商业模式能否成立"的验证阶段，Robotaxi 还没有。**

2. **回收环节的核心堵点是定价机制，不是产能。** 合规企业需承担环保、安全、税收、溯源管理等刚性成本，而非正规渠道无需这些投入，因此能给出更高的收购价；卖方只看价格的交易逻辑下，退役电池自然流向出价更高的一方〔M-0304 / AFT-047〕。**在"白名单定向回收机制"真正建立之前，把 527 亿元市场规模当作可兑现收入是不现实的。**

3. **产能利用率从 16.4% 提升 8–12pct 这个边际变化值得跟踪，但要区分来源。** 政策端"车电一体报废 + 数字身份证"是强制性的、去灰色的，而废料价格上涨（涨幅超 50%）是让合规企业"能赚钱"的因素。**两者中，前者改变渠道流向，后者改变盈利弹性——前者更根本。**

### 9.2 动力电池口径

**【事实】** 见 §4.1 完整八家横向表。

补充：宁德时代 FY2025 营收 4237.01 亿元（+17.04%）、归母净利 722.01 亿元（+42.28%）、毛利率 26.27%、锂电销量 661GWh（动力 541 / 储能 121）、产能 772GWh；2026H1 营收 2769.17 亿元（+54.80%）、归母净利 432.84 亿元（+41.98%）、毛利率 23.93%、电池销量合计 434GWh、产能利用率 94.86%、回购 200–400 亿元（第一阶段 CATL 条目）。

**【判断】**
- 宁德时代的份额回升（43.42%→46.7%）**部分依赖价格策略**，同期动力电池毛利率 -1.78pct——份额与毛利是跷跷板，不应同时线性外推。
- 二线电池厂中，**瑞浦兰钧是唯一毛利率同比提升者**，其 13.30% 来自综合毛利率 8.7%→13.3% 的完整修复，逻辑最干净；欣旺达毛利率修复幅度最大（+8.59pct）但被汇兑与减值吃掉；孚能科技是唯一收入与利润双降者。
- **储能接棒 + 二供分散化是同时发生的两件事**：前者给量，后者压价。二线厂要突围，必须在储能占比和客户结构上做出区隔，单纯扩产不足以改善盈利。

- 集团层面的现金流（经营现金流净额从 280.55 亿元降至 20.50 亿元）与净利下滑同向，**是全公司层面的问题而非汽车分部单独的问题**。

## 五、口径与数据纪律说明

1. **持股比例口径**：股东比例取自企查查「股东信息」（上市公司股东名册口径，T+0，源为国家企业信用信息公示系统），12 条记录合计约占总股本 63.08%；源数据比例为两位小数口径，逐条与「持股数 ÷ 总股本 1,741,985,086 股」四舍五入到两位小数后吻合（如 371,726,930 股 → 21.3393% → 21.3400%）。子公司比例取自「对外投资」的一层直接比例，**未做任何相乘或穿透推算**。
2. **信息日期锚定**：
   - 5 条直接股东关系：企查查未随记录返回独立日期，采用**工商变更核准日 2026-05-15** 作为信息日期锚点——该日为最新注册资本（= 总股本）登记生效日，且受益所有权形成日期同日，可与持股快照互相印证。
   - 5 条子公司关系：逐家调取该主体自身工商变更记录，取最近一次「投资人变更 / 注册资本变更」登记日；赛力斯海外（重庆）国际贸易有限公司无投资人变更记录，以设立日 2025-10-15 计。
3. **两套股东名单并存**：2025 年度报告（2026-06-16 公示）的「股东（发起人）及出资信息」为工商登记出资口径（8 名主体，认缴出资额合计 75000 万元，系历史出资登记），与「股东信息」的持股名册口径（12 条，含东风汽车集团、HKSCC 等二级市场持有主体）不同，二者不可直接比较，本表统一采用持股名册口径。
4. **HKSCC Nominees Limited** 为香港证券登记结算托管机构 nominee，境外主体无中国工商登记，统一社会信用代码标为「未披露」。
5. **未做推断**：实际控制人 / 受益所有人比例均逐字引用服务端股权穿透结果，未自行相乘重构穿透路径、未臆测中间层主体。
6. **「未披露」使用**：仅在源数据确实未提供该字段时标注（本次仅 HKSCC Nominees Limited 的统一社会信用代码一项）。

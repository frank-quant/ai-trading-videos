## 原文件阅读提示

这两份文件保留原最终交付的展示与历史记录。准确口径以[研究结果](../研究结果.md)、[最终漏斗](../funnel_counts.csv)和[测试集复算指标](../test_metrics.json)为准：

- PPT第1页“0 / 8”表示严格通过全部八层的策略数量为0；不能读作“通过0层”。
- PPT第6、8、11页部分图表标签按整数显示，小数精度不足；IR、收益和单位应查同页明细及配套结果。第10页右侧说明框遮住部分表格，完整数据在Excel与配套结果中。
- PPT第8、12页“AI中位+9.4%”口径不准确。本期采用A组9.46%、B组9.20%；20组随机各自中位数的中位数约−10.07%。主随机组中位数约−9.81%，不能与20组随机汇总混为一项。
- PPT第8页农场q25/q75的注释不准确：−23.47%、−7.31%是20组各自q25/q75再分别取中位数，并非20个中位数分布的四分位。Excel漏斗汇总第64行也是分列汇总：n为合并有效配置数12,620，中位/q25/q75分别是各组对应统计量的中位数。
- 原PPT中“分布几乎不重叠”“超额来自迭代学习”等表述不能由本次对照单独证明；生成机制、预算和风格差异见配套结果的研究限制。
- Excel漏斗汇总B16的“各路去重前计数”表述有误。表中最终A=3、B=14为全局L7去重后按组拆分，AI合计17，全局含随机组共21。

原交付中所引的本地报告、提交号与过程文件用于说明研究来源，本公开材料未逐一分发这些过程文件。可直接核对的CSV、JSON、候选配置与日收益位于上级results目录。历史可见性、开封后任务恢复及组合边界修正的披露见配套研究结果。

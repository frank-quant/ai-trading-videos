# 数据准备

原始行情不随仓库分发。需要自己的 Tushare Pro Token，以及 rules.md 7.6列出的各接口权限；免费或低积分账户不一定具备完整权限。下载前在自己的账户核查权限和频率。

运行 `python tools/fetch_tushare.py`。唯一凭据入口是环境变量 `TUSHARE_TOKEN`，不创建Token文件。下载单进程、每次请求间隔至少0.45秒；遇到权限、频率限制停止，普通错误连续3次停止。相同命令可续传，不提高并发。

- 抓取区间2013-01-01至2026-09-30；指数成分按2013-12至2026-09月末采样。
- 2024-12-31及以前写data/raw，2025-01-01及以后写data/sealed。
- 按接口合并parquet；data/MANIFEST.json记录来源、范围、行数与SHA256。
- 测试集文件落盘前在内存计算清单，开封前不读回统计内容。
- 交易日历可覆盖至2026年末；回测终点必须使用实际行情截止日，不能把未来日历空白计为零收益日。
- stock_basic是静态参考表；历史ST由namechange判断。指数成分为月度快照，不等于逐次调整公告的完整时点库。
- 允许fund_adj无权限时记录缺失，但复权组合结果届时可能不可用；不得用1填充缺失因子来伪造完整结果。
- 北向明细及披露制度存在覆盖与时点限制；不能把统一滞后一天视为已解决全部历史披露时点问题。使用相关因子前单独审核。
- 供应商后续修订、授权范围或接口覆盖变化，均可能导致重新抓取数据与案例清单不同。

完成下载后运行 `python tools/data_check.py`，检查raw侧覆盖、缺口、公告日期和复权。缺失关键接口时停止依赖它的研究，报告缺口，不生成占位假数据。

下载需要数小时、GB级磁盘空间；缓存和全部运行产物需额外空间。历史清单见 ../results/data_manifest.json，仅作核对，不会自动导入新研究。

# EP004 · 四个大模型同一道量化题

📺 看视频:[B站](https://www.bilibili.com/video/BV15HMS6DETZ/) · [YouTube](https://youtu.be/eLvZ_S8D3jU)

把 **Kimi K3 / Claude Opus 5 / Claude Fable 5 / DeepSeek V4 Flash** 关进同一场考试:
同一份题目、同一份数据、同一笔手续费、同一个目标函数,各自用**自己的官方 CLI** 写一套
能做多也能做空的量化策略。然后扔进一个它们从没见过的年份——那一年大盘跌 45%。

**四个策略在样本外全部由正转负,没有一个例外。**
但把收益拆成 alpha 和 beta 之后,四家露出了四张完全不同的脸。

本目录放的是**可复现的全部材料**:题目原文、脚手架、四家的完整交付物、验证脚本和结果。

## 三段数据划分

| 段 | 区间 | 用途 | 大盘年化 |
|---|---|---|---|
| TRAIN | 2021-01 ~ 2024-06 | hyperopt 在这里拟合 | +69.8% |
| VALID | 2024-07 ~ 2025-06 | 只评分、不拟合,用来选参数 | +28.6% |
| **TEST** | 2025-07 ~ 2026-07 | **最终考卷,四个模型全程不许访问** | **−45.0%** |

**TEST 段是物理隔离的**——不是靠提示词说「你别看」,而是把这段数据放在模型工作目录之外的
另一个盘符。即使模型跳过所有权限确认、自由执行任何命令,也扫不到。

> 这一步不做,后面所有结果都不成立。

## 考试规则

**锁死(改了直接判负)**

- 标的池:20 个 U 本位永续合约,固定在先,不许按表现挑币(幸存者偏差)
- 成本:单边 0.06%,资金费真实计入,不许调低
- 杠杆固定 1x,**必须能做多也能做空**,只做多判负
- 目标函数:由 [`scaffold/EP004ValidLoss.py`](scaffold/EP004ValidLoss.py) 提供,不许自己写

**开放(模型自定)**

- 策略家族、时间周期(30m/1h/4h/1d)、进出场逻辑、回撤控制、换手控制
- 搜索轮数:只给上限 2000,**用多少自己判断**

题目原文见 [`prompts/GOAL.md`](prompts/GOAL.md)(四家收到的是逐字相同的同一份,英文)。

## 怎么自己复现

### 0. 环境

- Freqtrade 2026.6(Docker)
- 20 个 U 本位永续合约,4 种周期(30m/1h/4h/1d)+ mark + funding,2021-01 → 2026-07
- 把 **2025-07 之后的数据单独放在另一个目录**,优化阶段不要挂载进去

详细步骤见 [`RUNBOOK.md`](RUNBOOK.md)。

### 1. 复现某一家的结果

把 `submissions/<model>/` 里的策略和 `config.json` 放进你的 Freqtrade 环境,
按 [`RUNBOOK.md`](RUNBOOK.md) 里的命令跑三段回测即可。

**三个参数必须带**:

| 参数 | 为什么 |
|---|---|
| `--cache none` | Freqtrade 默认缓存会复用旧结果,改了代码也看不出来 |
| `--fee 0.0006` | 统一成本,覆盖模型自报的 fee |
| 挂对数据目录 | TRAIN/VALID 用完整数据,TEST 段单独挂 |

### 2. 自己出一次题

用 `prompts/GOAL.md` + `scaffold/` 就能复刻整场考试。
把 scaffold 拷进一个干净的 Freqtrade 目录,让模型读 GOAL.md 和 README_FOR_MODEL.md 即可。

## 验证脚本

| 脚本 | 作用 |
|---|---|
| [`scripts/factor_causality_check.py`](scripts/factor_causality_check.py) | **未来函数主闸**。对同一时点,用全量数据算一遍信号,再用截断到那一刻的数据算一遍;不一致=用了未来数据 |
| [`scripts/deflated_sharpe.py`](scripts/deflated_sharpe.py) | Deflated Sharpe。回答「以你这个搜索规模,纯靠运气能刷到多高」 |
| [`scripts/mc_bootstrap.py`](scripts/mc_bootstrap.py) | 蒙特卡洛分块自助重采样,给出 prob(profit) |
| [`scripts/hyperopt_plot.py`](scripts/hyperopt_plot.py) | 搜索收敛曲线 + 训练/验证过拟合散点 |
| [`scripts/usage_cost.py`](scripts/usage_cost.py) | 从本地日志统计 token 用量,按公开单价折算等效成本 |
| [`scripts/make_video_charts.py`](scripts/make_video_charts.py)<br>[`scripts/make_metric_charts.py`](scripts/make_metric_charts.py) | 复现 `results/charts/` 里的全部图表 |

> ⚠️ Freqtrade 自带的 `lookahead-analysis` **对横截面策略会误报**——它把边界那根 K 线的
> 排名变化当成偏差。用 `factor_causality_check.py` 的全量 vs 截断对照更可靠。

## 几个值得单独看的发现

**三家主动放弃了自己跑出来的最高分参数,一家接住了。**
Opus 5 在 design.md 里算出训练/验证夏普的相关性只有 r=0.21,称验证集排名「基本上是噪音」,
并写道取最高分那组等于「取 300 次抽样里最大的那个噪声」。图见 `results/charts/argmax_choice.png`。

**验证集的信噪比本身就能提前预告成败。**
四家的 train/valid 相关性 r 分别是 +0.54 / +0.21 / −0.06 / −0.28,**和样本外排名几乎同序**。
样本只有 4 个,算强提示不算定论,但这个量是搜完参数当场就能算的。

**周期选择比参数调优影响大得多。**
同一个因子,30 分钟不控换手一年 12,745 笔亏 44.7%;换成 4 小时加最短持仓,436 笔反而赚 3.28%。
图见 `results/charts/turnover_cost.png`。

**成本和产出没有关系。** 见 `results/charts/cost_alpha.png`。

## ⚠️ 这份实验的局限

1. **样本外那一年是熊市(−45%),训练和验证都是牛市。** 这是最诚实的压力测试,但不是中性样本,换个年份结论可能不同。
2. **幸存者偏差**:这 20 个标的是 2026 年回头挑的,更早退市的不在池子里。所有回测都躲不掉这一条。
3. **滑点乐观**:扁平 0.06%,无市场冲击模型,真实交易只会更差。
4. **样本外仅 1 年 × 20 个高相关标的**,统计上偏薄,蒙卡和 DSR 只能部分兜底。
5. 评分里**稳健性、表现、成本有客观依据**;代码质量与解释诚实度是主观打分,依据已在报告中列出。

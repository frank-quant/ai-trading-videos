## 第 3 层 · 稳健性 + alpha/beta 归因

### alpha/beta 分解(逐日盯市权益回归大盘)

| | beta | R² | **年化 alpha** | 实际收益 | beta 拖累 | **alpha 贡献** | 净敞口 |
|---|---|---|---|---|---|---|---|
| Kimi K3 | 0.12 | 0.30 | **−29.5%** | −29.8% | −5.5% | **−24.3%** | 17.7% |
| Opus 5 | **0.03** | 0.03 | **−20.2%** | −19.6% | −1.3% | **−18.2%** | 8.1% |
| **Fable 5** | 0.31 | **0.76** | **+7.9%** ✅ | −7.5% | **−14.0%** | **+6.5%** | **34.1%** |
| **DeepSeek** | 0.15 | 0.38 | **−0.2%** | −7.1% | −6.8% | **−0.3%** | 15.0% |

**读法**:
- **Fable 5 是唯一有正 alpha 的**(+7.9%)。它亏钱纯粹因为 34% 净多头敞口撞上熊市,被 beta 拖走 14 个点。**若做成真中性,这一年约 +6.5%。**(事后归因,反事实推算)
- **Opus 5 最接近真中性**(beta 0.03、净敞口 8.1%)——做空确实起作用了,大盘跌对它几乎无影响。但它的选股是负 alpha。
- **DeepSeek 的 alpha 约等于 0**(−0.2%)——不好不坏,亏的几乎全是 beta。
- **Kimi 负 alpha 最深**(−24.3%),选股方向反了。

|---|---|---|---|---|

| **蒙卡 prob(profit)** | **0.0%** | 0.1% | **8.9%** | 0.9% |
| **DSR** | **0.094** ❌ | **0.868** 🟡 | 0.715 🟡 | **0.868** 🟡 |
| 纯运气基线夏普 | 2.55(观察 1.57) | 0.78(观察 1.62) | 1.53(观察 1.98) | 1.44(观察 2.18) |

> **DSR 最狠的一刀**:Kimi 搜了 400 轮,验证夏普 1.57,**而纯靠运气就能刷到 2.55** → DSR 0.094,验证成绩在统计上完全不显著。

## 第 5 层 · 工程与判断力

**四家不约而同的专业操作**(本期最大发现之一):

| | 轮数/上限 | 拒绝 argmax 的理由 |
|---|---|---|
| Kimi | 400/2000 | 弃 argmax e370(train −0.38/valid 2.68),称其为「本题定义的失败模式」 |

| DeepSeek | 500/2000 | 同样未跑满 |

**三家都在自评里主动承认「验证集已经等于训练集的一部分」**,都引用 DSR 论证少搜。**没有一家掉进"调到最漂亮"的陷阱。**

## 三个结论

1. **只看单价会挑错。** Fable 标价是 Opus 的两倍,总账单却只有 Opus 的 26%——它 109 次调用、735 万 token 就交货,Opus 用了 330 次、**5906 万 token(8 倍)**。**真正的成本驱动是 token 总量,不是单价。**
2. **花的钱和产出没有关系。** 花最多的 Opus(¥363)alpha 是 −20.2%;花第二少的 Kimi(¥16)alpha 是 −29.5% 最差;而唯一造出正 alpha 的 Fable(¥95)排在中间。**这条曲线上找不到任何单调关系。**
3. **但贵确实买到了东西——只是不是收益。** Opus 的代码质量(9 分)和方法论自省(10 分,唯一算出 r=0.21 并给出 12 近邻选参法)都是四家天花板。**它买的是工程深度。**

## 诚实声明

- Kimi 的 ¥15.62 已用 Moonshot 平台**逐请求明细**核对(导出窗口 2026-07-26 ~ 08-02):该窗口内**全部 71 次请求都在 7月30日**,即本期整轮。月视图上 7月21、22 日那两根柱在导出窗口之外,属更早的准备工作,与本期无关。
- Opus / Fable 是**等效成本而非实付**。会员制下这道题的实际边际成本是 0,这个数字回答的是"如果按 API 计费会花多少"。
- 四家的缓存计价规则差异极大,**跨厂商比较天然有口径差**,不宜精确到个位数解读。以 DeepSeek 官方明细为例(单位:元/百万 token):

  | | 缓存命中 | 缓存未命中 | 输出 |
  |---|---|---|---|
  | deepseek-v4-flash | **¥0.02** | ¥1.00 | ¥2.00 |

# 结论

**四个顶级 AI,各做对了一半,没有一个两样都对:**

- **Fable 5**:选股对了(+7.9% alpha),仓位错了(34% 净多头)
- **Opus 5**:仓位对了(真中性),选股错了(−20% alpha)
- **DeepSeek**:两样都不功不过(alpha ≈ 0),但风控最好(回撤 14%)
- **Kimi K3**:两样都没做对

**共同事实**:四家在验证集上的夏普是 1.24 / 1.34 / 1.87 / 1.93——任何人看到都会说"能用"。样本外全部转负。

**而且它们都做对了防过拟合的功课**(只搜 300–500 轮、拒绝最优参数、自评承认验证集污染)。**说明真正的杀手不是调参技巧,是市场变天**(训练验证是牛市,样本外跌 45%)。

## 局限与诚实披露

1. **样本外是熊市**(−45%),训练验证都是牛市——这是最诚实的压力测试,但**不是中性样本**
2. **幸存者偏差**:这 20 个币是 2026 年回看选的,2021 年就退市的不在池子里
3. **滑点乐观**:扁平 0.06%,无市场冲击模型,真实成本更高(成本敏感性测试可覆盖)
4. **样本外仅 1 年 × 20 个高相关标的**,统计上偏薄;蒙卡和 DSR 只能部分兜底
5. **成本维度四家口径不完全一致**:DeepSeek/Kimi 是平台实扣,Opus/Fable 是会员无账单、按本地日志折算的等效成本;且各厂商缓存计价规则不同,不宜精确解读
5. **各家 harness 不同**(Kimi Code / Claude Code / Codex),测的是「模型+CLI 组合」,不是裸模型

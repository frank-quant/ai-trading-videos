# AI Agent 金融入门（MiniMax Code）

面向金融工作的 AI Agent 操作案例，包含实际执行提示词和主要交付物，供读者查看、复现和继续修改。

## 仓库内容

| 案例 | 主要内容 |
| --- | --- |
| B1 金融数据调用 | 赛力斯与比亚迪的年度、半年度财务数据及来源 |
| B2 企业信息查询 | 工商主体、一层股权关系与交互图谱 |
| B3 财报与文件处理 | 两期财务数据摘录、官方来源与单位换算 |
| B4 Excel 生成与建模 | 可调整假设并保留公式的 Excel 情景表 |
| B5 数据分析与出图 | 历史行情、区间收益、最大回撤与图表 |
| C1 新能源汽车产业链研究 | 研究报告、Excel 底稿、投资关系图谱和离线 HTML 报告 |
| C2 赛力斯股票量化分析 | 均线信号、T+1 回测、Excel 模型、图表、QA 与复现包 |

## 如何复现

1. 打开 `prompts/MiniMax_Code_全部执行提示词.md`，选择一个案例。
2. 在 MiniMax Code 中新建会话，并连接一个新的空文件夹。
3. 按文档中的顺序发送提示词，让 Agent 自行下载需要的财报、行情和其他资料。
4. 打开生成结果，与 `deliverables/` 中对应案例的文件对照。

不同案例建议分别新建会话和项目目录，避免材料、口径和交付物混在一起。

## 如何查看交付物

- **HTML**：直接用浏览器本地打开。C1 的 `research.html`、`investment_graph.html` 和 C2 的 `moving_average_report.html` 支持交互；访问外部原始来源仍需联网。
- **Excel**：使用 Excel、WPS 或其他兼容软件打开，查看数据、假设、公式和 QA。
- **Markdown / CSV / 日志**：使用文本编辑器打开。
- **复现材料**：C2 的 `ma_reproduction/` 已解压，可直接查看脚本、数据和核验材料。

## 数据与研究边界

- 案例使用公开财报、行情、工商信息及公开研究资料，不包含账号、密码、API Key 或登录凭据。
- 交付物保留来源、计算口径和核验记录，但不代表全部数据与业务结论已经由第三方复核。
- 历史行情和回测结果仅用于功能演示，不构成投资建议，也不代表未来收益。
- 代码与文档遵循仓库根目录的 MIT License；第三方财报、数据库返回和原始资料的权利与使用条件以原提供方为准。

## C2｜赛力斯股票趋势、移动平均线与教学回测

### 第 1 步｜取得并检查真实行情

```text
帮我取赛力斯（601127.SH）2023-06-01到2026-10-23的前复权日线，再取同期沪深300价格指数。保存 prices.csv、prices_bench.csv 和 sources.md。
先检查证券代码、实际首末交易日、重复日期、缺失值、开收盘字段、复权方式和数据来源。股票和指数按共同交易日对齐，原始文件不要覆盖，缺数据就直说。
```

### 第 2 步｜生成技术快照和均线信号

```text
用最近120个交易日给出MA5/20/60、RSI14、MACD和评分理由，保存 technical_snapshot.md。评分只代表当日技术快照，不证明策略有效。
再按完整样本计算SMA5/20/60、EMA12/26、均线斜率、排列状态和金叉／死叉，保存 indicators.csv 和 signals.csv。前59行标为预热，不形成交易信号；金叉或死叉只在实际交叉时记录，不能每天重复发信号。
```

### 第 3 步｜按 T+1 规则做两版回测

```text
用SMA5和SMA20的交叉做教学回测：金叉后下一交易日开盘全仓买入，死叉后下一交易日开盘清仓，不做空，预热期不交易，样本末不强制平仓。
分别生成零成本和含费账本，含费按单边0.075%计算，不计印花税和过户费。保存 Ledger_Gross（零成本）和 Ledger（含费）两张表，列出每笔信号、执行日期、成交价格、持仓、费用和每日净值。
```

### 第 4 步｜比较策略、买入持有和沪深300

```text
接着算策略累计收益、年化收益、最大回撤、交易次数、持仓天数和实际费用，再与同期买入持有及沪深300价格指数比较，保存 metrics.csv。
画价格与均线及买卖点、策略净值与基准、回撤三张图。含费和零成本都要展示，费用造成的期末净值差与实际支付费用也要分开。
如果策略跑输基准或出现亏损，直接展示，不要换区间或调参把它做成好看的结果。
```

### 第 5 步｜独立复核指标和结果

```text
请独立复核这次结果：随机抽20个交易日检查均线，SMA用前缀和差分复核，EMA用显式循环复核；净值用对数收益累加再取指数复核，最大回撤用显式循环维护峰值复核。
检查预热行数、未来数据、信号与成交时点、成本、基准和数据来源。把检查过程和未解决的问题保存为 qa_report.md，发现错误先修正再继续。
```

### 第 6 步｜生成 Excel 底稿和离线研究报告

```text
用Excel插件生成 moving_average_analysis.xlsx，包含 Assumptions、Prices、Indicators、Ledger、Ledger_Gross、QA、Summary、Prices_Bench 八个工作表，参数放在 Assumptions 页面，可以修改后联动重算。

HTML要离线双击打开，样式、数据和脚本都内联。最后整理 qa_report.md、skill_invocations.log 和 ma_reproduction.zip。
```

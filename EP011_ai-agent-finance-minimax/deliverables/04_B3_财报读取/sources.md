| 营业收入 | 57,493.12 | 62,401.72 | **-4,908.60** | **-7.87%** | -7.87% ✓ |

```
营业收入   差额 = 57,493.11912858 - 62,401.72281380 = -4,908.60368522 → -4,908.60 百万元
           同比 = -4,908.60368522 / 62,401.72281380 = -7.87%

归母净利润 差额 = -1,716.86887867 - 2,940.89021611 = -4,657.75909478 → -4,657.76 百万元
           同比 = -4,657.75909478 / 2,940.89021611 = -158.38%
```

自算同比与报告披露的同比增减（-7.87%、-158.38%）完全吻合，可作为换算与取数正确性的旁证。

1. **下载**：按上文链接下载两份 PDF；上交所静态服务器需先解 `acw_sc__v2` 反爬 Cookie。
2. **取数**：用 PDF 文本层按页提取（PyMuPDF），定位「主要会计数据」表与「合并利润表」；

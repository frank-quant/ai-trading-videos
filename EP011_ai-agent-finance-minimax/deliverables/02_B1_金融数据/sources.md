# 数据来源记录：赛力斯 vs 比亚迪 经营规模与盈利对比（2025 年度 + 2026 年上半年）

## 查询概览

| 项目 | 内容 |
| --- | --- |
| 查询日期 | 2026-11-01 |
| 数据来源 | iFinD（同花顺金融数据），经 Connector `thsifind` 提供 |
| 调用方式 | `mcode-tools connector call connector__thsifind__get_security_indicators --args-file <args.json>` |
| 参数结构来源 | `mcode-tools connector tool connector__thsifind__get_security_indicators`（已检视 input_schema：必填 `market`、`query`） |

本次查询（2025 年度与 2026 年上半年两次取数）**仅使用金融数据工具（iFinD）返回的数据**，未使用网页搜索、浏览器抓取或本地已有文件中的任何数值。

**本文档含两条独立查询记录**：第一部分为 2025 年度（交付文件 `data.csv`），第二部分「补充查询：2026 年上半年」为 2026H1（交付文件 `data_h1.csv`），详见文末。

## 实际使用的工具调用

1. 单公司查询——赛力斯
   - query：`赛力斯 601127.SH 2025年年报合并口径的营业总收入、归属于母公司所有者的净利润，报告期2025-01-01至2025-12-31，单位：元`
2. 单公司查询——比亚迪
   - query：`比亚迪 002594.SZ 2025年年报合并口径的营业总收入、归属于母公司所有者的净利润，报告期2025-01-01至2025-12-31，单位：元`
3. 双公司交叉校验查询
   - query：`赛力斯(601127.SH)、比亚迪(002594.SZ) 2025年年度累计(年报合并报表)营业总收入、归属于母公司所有者的净利润、营业总收入同比增长率、归属母公司股东的净利润同比增长率`

三次调用返回的两项核心指标完全一致（第 1、2 次与第 3 次逐字相同），日期列均为 `20251231`，`indicators_params` 中两项指标的报表类型均为“合并报表”。

单位换算（亿元 → 百万元，×100）：

- 赛力斯：营业总收入 1650.5364亿 = 165,053.64 百万元；归母净利润 59.5679亿 = 5,956.79 百万元
- 比亚迪：营业总收入 8039.6496亿 = 803,964.96 百万元；归母净利润 326.1902亿 = 32,619.02 百万元

## 一致性校验

用接口同时返回的同比增长率反推上年同期基数，与 FY2025 金额自洽，佐证取数为全年累计数而非单季数：

- 赛力斯：165,053.64 ÷ (1 + 13.6922%) ≈ 145,167 百万元；5,956.79 ÷ (1 + 0.1823%) ≈ 5,946.0 百万元
- 比亚迪：803,964.96 ÷ (1 + 3.4568%) ≈ 777,102 百万元；32,619.02 ÷ (1 − 18.9677%) ≈ 40,254 百万元

## 缺失项与说明

- **缺失项：无。** 营业总收入、归属于母公司所有者的净利润两项，两家公司均完整取得。
- `data.csv` 中的「归母净利率」列为派生值（归母净利润 ÷ 营业总收入），非工具直接返回，赛力斯 3.61%、比亚迪 4.06%。
- 接口还一并返回了“净利润”（含少数股东权益）：赛力斯 61.4674亿、比亚迪 337.6076亿。因用户要求的是归母净利润口径，该项未列入 `data.csv`。
- 接口返回的「单季度.*」系列指标对应 2025 年第一季度，仅为接口附带输出，未用于本表。
- 未使用 `search_notice`（公告语义检索）等其他 iFinD 工具，核心指标全部由 `get_security_indicators` 直接取得。
- 技术备注：在 PowerShell 下直接以 `--args` 传入含中文的 JSON 会被命令行编码破坏并报 “Connector arguments must be valid JSON”，故改用 UTF-8 参数文件 `--args-file` 传参，查询语句与结果不受影响。

# 03 · 让 ZCode 设计四个模块

**视频 06:23** · 先要设计,不要代码。

```
我用 TradingAgents-CN 分析 A 股，有四个地方不好用，你帮我设计一套插件补上：

1. 报告太长，六千多字，早上开盘前根本读不完
   —— 要能自动提炼成两百字左右的短版

2. 跑完不吭声，得自己开网页去刷
   —— 要能主动推送到飞书这类 IM，还能设定时

3. 换个模型对比效果太麻烦，只能一个个手动跑、手动记数据
   —— 要能一条命令跑多个模型，出一张硬指标对比表

4. Agent 辩论的过程只能在 UI 里翻，不够清晰
   —— 要能渲染成可视化的回放

设计要求：
- 四个功能做成四个独立模块，每个模块用一个英文单词命名，见名知意
- 代码放在项目外面的 studio/ 目录，不改原项目任何文件，将来要单独开源
- 一个统一的命令行入口，一份集中的配置文件
- 再给一份 Docker 补丁，方便别人挂到已有部署上

先给我目录结构和模块划分，先别写代码。
```

## 两个设计要点

**「每个模块用一个英文单词命名，见名知意」**

不指定名字,但把命名方式框死。这四个功能配单词,自然落点就是
`digest` / `notify` / `replay` / `compare`。

**「先给我目录结构和模块划分，先别写代码」**

这句让它先输出架构而不是甩一堆文件。确认结构对了再要实现,
不然改起来成本高得多。

## ⚠️ 如果 studio/ 已经存在

ZCode 会先扫项目,看到已有目录就会说"你已经有这套东西了",而不是给你设计。
录制或复现前把它挪走:

```bash
mv studio studio_bak
```

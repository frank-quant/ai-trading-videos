## 两条经验

**给授权,不然它每步都问你**

装机那条里最后一句「遇到问题你自己查自己改」很关键。
没这句,它每执行一个命令都会停下来等你确认,过程会很碎。

**一次一个模块,别一口气要四个**

一次性要四个模块的完整实现,大概率给你一堆跑不起来的骨架。
先要设计、确认结构,再一个一个要实现。

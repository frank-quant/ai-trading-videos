## 使用方法

1. 直接查看成果：从上表进入对应案例，下载PPT、Word或Excel后打开；Markdown报告可直接阅读，HTML报告建议下载后在浏览器查看。
2. 重新执行任务：为每项任务新建独立工作目录，复制对应提示词正文，让执行工具在该目录生成自己的`output/`。任务要求自行查资料；实际可访问的数据源和已启用技能以自己的环境为准。
3. ETF离线复算：先复制该案例完整的`output/`到新目录，按照其运行说明安装依赖并执行。此操作复现的是原始代码结果，分红错误不会因重复运行自动修复。
4. 阅读前先看[复核说明](复核说明.md)，了解已确认的问题、抽查范围和待核事项。

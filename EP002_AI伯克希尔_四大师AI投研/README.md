别再直接问 AI「这股能不能买」了。同样一个问题,随手问 chatbot 给你的是一段正确的废话;
用对方法,给你的是一份带交叉验证、四个视角、明确标注不确定性的投研报告。

这期不是荐股,是**方法**:怎么用 Claude Code + 一套现成的投研技能,把 AI 变成一个"投研团队"。

## 随手问 chatbot 为啥做不了投研

- **会编数字**:让它报营收/毛利率,能一本正经给你个错的,还不给来源
- **没有信源**:结论悬空,没法核对也没法引用
- **被共识带跑**:网上一致看多,它大概率跟着看多
- **不可复现**:今天问和明天问结论不一样,没法横向比多家
- **没有结构**:想到哪说到哪,缺一个完整框架

## 有方法地用 AI 做投研:四件套

1. **结构化视角**——不问开放题,用固定框架逼它说全。这里用四大师对撞:
   - 段永平:是不是门好生意?
   - 芒格(逆向):它会怎么死?
   - 巴菲特:现在贵不贵、有没有安全边际?
   - 李录:10 年后还在、还赚钱的确定性?
2. **多 Agent 并行独立**——派几个互不通气的 agent 各查各的,再对撞,而不是一个模型自说自话
3. **工具化校验**——关键数字用精算 + 跨源交叉验证 + 市值手工核对,不让模型"凭印象"
4. **强制标注不确定性 + 可复现**——数据不够就标 A/B/C 信息等级、明说"需验证"

`ai-berkshire` 就是把这四件套封装成了一组能在 Claude Code 里一条命令调用的技能。
